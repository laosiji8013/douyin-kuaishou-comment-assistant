# 脱敏记录

公开候选版没有包含历史私密测试语料。处理结果如下：

| 内容 | 公开处理 |
| --- | --- |
| 历史推广评论库 | 全部移除，用 5 条中性虚构示例替换 |
| 历史搜索关键词 | 用“公开教程、经验分享、工具演示”替换 |
| Cookie、Storage、浏览器资料 | 不复制，路径加入 `.gitignore` |
| 截图、日志、缓存、`.DS_Store`、`.pyc` | 不复制并加入忽略规则 |
| 本机绝对路径 | 不进入代码和文档 |
| 抖音/快手选择器 | 保留为历史适配基础，并声明可能过期 |
| 随机时间和随机事件 | 集中到公开 JSON 配置并逐项解释 |
| 自动发送与自动点赞 | 评论改为候选审核后自动填写并发送；点赞仍逐次确认 |
| “永久运行”和无人值守循环 | 改为有上限的交互式会话 |

公开版不声称是历史文件的逐字复制；它是基于历史结构整理的、可审阅的安全发布版本。
